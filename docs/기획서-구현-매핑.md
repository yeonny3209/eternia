# 기획서 ↔ 구현 매핑

기획서의 어느 절이 어느 파일이 됐는지 적어 둔 표입니다.
기획서를 고칠 때 무엇을 같이 고쳐야 하는지 여기서 찾으면 됩니다.

> 원본 기획서 `에테르니아_RPG_기획서_v2.md`와 별책 `에테르니아_PvP_기획서.md`는
> 이 `docs/` 폴더에 함께 두는 것을 권장합니다. 코드 주석이 절 번호로 원본을 참조합니다.

## 검증 장치

기획서의 규칙 중 코드가 자동으로 지키게 만든 것들입니다.
어기면 CI가 막습니다.

| 규칙 | 검사하는 곳 |
|---|---|
| 히든 퀘스트는 `autoTrack: false` | `validate-data.ts` |
| 히든 직업 성능 상한 105% | `validate-data.ts` |
| 신화 등급은 거래 불가 | `validate-data.ts` + 아이템 테스트 |
| 등급별 접사 줄 수 상한 | `validate-data.ts` + 아이템 테스트 |
| PvP 계수 ≤ PvE 계수 | `validate-data.ts` |
| 여명 마을에서 모든 맵 도달 가능 | `validate-data.ts` |
| 선행 퀘스트 순환 참조 없음 | `validate-data.ts` |
| 동레벨 일반 몬스터 3~5타 사망 | `formulas/combat.test.ts` — monsters.json 전체 검사 |
| 필드 보스 60~120초 | `formulas/combat.test.ts` |
| 무적 프레임은 서버 시각으로만 판정 | `combat/combatant.test.ts` |
| API가 히든 정보를 흘리지 않음 | `server/routes/routes.test.ts` |
